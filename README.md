# Villain Society 🖤

> Built for the ones who never fit.

A coming soon landing page for Villain Society — a streetwear clothing brand dropping August 2026. Built to collect email signups from Villain World before launch day.

---

## 🔥 Live Site

[villain-society.com](https://d1p8054ur0v65i.cloudfront.net) — coming soon

---

## 🛠 Tech Stack

- **React** — frontend framework
- **Vite** — build tool
- **Tailwind CSS** — styling
- **AWS S3** — hosting
- **AWS CloudFront** — CDN + HTTPS
- **AWS Lambda** — serverless email handler
- **AWS API Gateway** — REST API
- **AWS DynamoDB** — email storage

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/AshantiC22/villain-society.git

# Navigate to project
cd villain-society

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
