# Villain Society — Product Requirements Document

## Overview

A coming soon landing page for Villain Society clothing brand.
Goal: collect email signups before August 1, 2026 launch.

## Target Audience

Gen Z streetwear fans who identify as different,
bold, and outside the norm. Community: Villain World.

## Success Metric

Maximum email signups before August 1, 2026.

## Tech Stack

- Framework: React + Vite
- Styling: Tailwind CSS
- Animations: CSS keyframes
- Deployment: AWS S3 + CloudFront
- Email Collection: AWS Lambda + API Gateway + DynamoDB

## Components

- Navbar.jsx
- Hero.jsx
- VillainStatus.jsx
- CountdownTimer.jsx
- EmailSignup.jsx
- ProgressBar.jsx
- Footer.jsx

## Color Palette

- Background: #0A0A0A
- Red Primary: #CC0000
- Red Accent: #FF0000
- Cream White: #F5F0E8
- Card Gray: #2A2A2A

## Typography

- Heading: Bebas Neue or horror font (commercial license)
- Body: Space Grotesk
- Accent: Custom grunge font

## Launch Date

August 1, 2026

## Out of Scope (Phase 2)

- Shopping cart
- Product pages
- Social media links
- Mobile app
